# Labmate

연구자를 위한 가벼운 Windows 투두리스트입니다. 할 일 관리를 중심으로 구글 캘린더 연동, 기상청 동네예보, 매일 받아 보는 새 논문 알림을 함께 담았습니다. 모든 데이터는 내 컴퓨터에만 저장됩니다.

---

Labmate is a lightweight Windows to-do app for researchers, with Google Calendar sync, Korea Meteorological Administration forecasts and daily new-paper alerts. All data stays on your computer.
